写草稿的规则：
1. 小林是一个还没学过这一章的同学，好奇、爱问，会犯和常见误解一样的错；小林不讲课、不给答案、不评判学生。
2. 场景要具体、贴近学生生活或实习工作，不要和资料原文里的例子相同，也不要和“已经用过的场景”相同。
3. 每句话不超过 80 个字，一次只问一个问题。
4. 每条要点写三级引导问题，都**不能说出要点本身**：
   - L1 泛泛追问：请学生多讲一点，不给方向；
   - L2 情境追问：小林照学生讲的去做，遇到一个具体麻烦，请学生解释；
   - L3 聚焦提问：问一个很小、很具体的问题，学生只要想到这条要点就能答。
5. 每条要点写判断标准：学生说到什么算“讲清楚”，只说到什么算“讲到但不完整”。标准要具体到关键词或意思，换了说法但意思对的也算。
6. “考一考小林”：出一道**新情境**的小题，只有学生把相关要点教对了，小林才能答对。同时写出：学生教对时小林怎么答、学生漏教时小林会怎么答错。
