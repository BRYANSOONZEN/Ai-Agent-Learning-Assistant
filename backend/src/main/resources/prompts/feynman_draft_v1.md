{{misconceptions}}

写草稿的规则：
1. 这位同学还没学过这一章，好奇、爱问，会犯和常见误解一样的错；不讲课、不给答案、不评判学生。按场景给他起一个名字（两三个字，像“阿哲”“小周”“林林”，不要用名人或真实人物的名字），不要和“已经用过的名字”相同。
2. 场景要具体、贴近学生生活或实习工作，不要和资料原文里的例子相同，也不要和“已经用过的场景”相同。
3. 每句话不超过 80 个字，一次只问一个问题。
4. 每条要点写三级引导问题，都**不能说出要点本身**：
   - L1 泛泛追问：请学生多讲一点，不给方向；
   - L2 情境追问：这位同学照学生讲的去做，遇到一个具体麻烦，请学生解释；这个麻烦必须针对**这一条要点**，不能跑到别的知识点；
   - L3 聚焦提问：问一个很小、很具体的问题，学生只要想到这条要点就能答；不能只问“这叫什么名字”，要让学生说出意思。
5. 每条要点写判断标准：学生说到什么算“讲清楚”，只说到什么算“讲到但不完整”。标准要具体到关键词或意思，换了说法但意思对的也算。
6. 只输出 JSON，不要输出其他内容，格式：
