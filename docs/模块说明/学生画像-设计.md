# 学生画像：每章画像 + 课程四维（设计）

> 2026-11-25 组内定稿。参考了组员给的《章节学习分析与课程五维画像》方案：**结构用它的（每章分析 + 课程画像）**，计分口径用我们的（只算第一次作答、知识点绿 / 橙 / 红），课程画像从五维改为**四维**（去掉“练习参与率”）。
>
> 代码：`profile/service/CourseProfileService`；接口 `GET /api/profiles/me/courses`、`GET /api/profiles/me/courses/{id}`；页面 `views/profile/ProfileView.vue`。全部现算，不另外存表。

---

## 一、为什么这样设计

| 决定 | 理由 |
|---|---|
| 分两层：每章画像 + 课程画像 | 每章在学的过程中就能看到哪里还没掌握，及时补；课程画像是学完后的整体描述 |
| 知识点直接用绿 / 橙 / 红 | 和练习、小助手、老师干预用的是同一套判断（第一次作答），学生在哪里看到的颜色都一样 |
| AI 对话不进画像分数 | AI 对话只做诊断、不打分（费曼对话的设计），只算“流程有没有完成” |
| 课程画像只在全部章节学完后开放 | 没学完时比例会一直变，看了容易误解；没学完先看每章 |
| 四维、去掉练习参与率 | 练习必须交卷才能解锁下一项，学完整门课时参与率基本都是 100%，没有区分度，而且和完成度重复 |
| 没有数据就显示“暂无数据” | 不用 0 或 100 补；四维不全时不画多边形 |
| 各章合并时分子、分母相加再除 | 不平均百分比（各章题数不同，平均会算错） |
| 不做总分、不排名 | 四维是学习过程的描述，不是成绩，也不推断性格、态度 |

## 二、每章画像（学的过程中一直显示，学完是“学习小结”）

| 部分 | 怎么算 | 数据从哪来 |
|---|---|---|
| 学习流程进度 | 已完成的项 ÷ 本章全部项（含 AI 对话） | 学习项、完成判定（视频看到 90%、文档读满 30 秒并点已读完、练习交卷、对话结束） |
| 内容进度 | 已完成的视频、文档、练习 ÷ 本章全部视频、文档、练习（不含 AI 对话） | 同上 |
| 练习交了几组 | 交过卷的练习 ÷ 本章练习 | 作答记录（按练习项） |
| 第一次作答全对 | 每道题第一次作答全对的题数 ÷ 已判的题数；等老师确认的简答另外显示，不算错 | 作答记录 |
| 知识点颜色 | 绿 = 第一次就掌握（原始掌握度 ≥ 0.8）；橙 = 第一次没掌握，补练后补回来了；红 = 还没补回来；灰 = 没练过 | 掌握度表（原始掌握度、补练结果，见练习与掌握度-设计.md 第五节） |
| 一句话小结 | 程序按上面的数字拼出来，不调大模型 | — |

示例：
> 学习流程完成 7/7 项（AI 对话只算完成状态）；内容完成 6/6 项；练习交了 1/1 组。第一次作答 14/20 题全对。知识点：4 个第一次就掌握，1 个补回来了，2 个还没掌握。

## 三、课程四维（全部章节学完后开放）

| 维度 | 算法 | 数据从哪来 | 没数据时 |
|---|---|---|---|
| **学习持续性** | min(1, 有效学习日 ÷ 7)，看参考日在内的最近 14 天。**有效学习日** = 这一天看视频、文档累计 ≥ 30 秒（各章先加起来再比），或者交过 ≥ 1 道已判的题 | 页面停留记录（只算视频、文档）、作答时间；AI 对话不算 | — |
| **学习完成度** | 完成的视频、文档、练习 ÷ 全部视频、文档、练习 | 完成判定 | 课程没有内容：暂无数据 |
| **按时完成率** | 截止前第一次交卷的练习 ÷ 已经过了截止时间的练习 | 练习的截止时间、第一次交卷时间 | 还没有到截止时间的练习：暂无数据 |
| **有效作答正确率** | 第一次作答全对的题数 ÷ 已判的题数 | 练习作答记录（每道题只看第一次；等老师确认的不算） | 还没有已判作答：暂无数据 |

**参考日**：全部学完时 = 最后一项完成的那一天（之后再打开，持续性不会无缘无故变低）；没学完时 = 今天。

**例子**（两章，人工构造）：

| | 第 1 章 | 第 2 章 | 全课 |
|---|---|---|---|
| 有效学习日（近 14 天） | {D−10, D−9, D−8} | {D−8, D−3, D−1, D} | 合并去重 6 天 → 6/7 = **85.7%** |
| 完成的内容 | 4/4 | 4/4 | 8/8 = **100%** |
| 按时交的练习 | 2/2 | 1/2 | 3/4 = **75%** |
| 第一次作答全对 | 8/10 | 3/6 | 11/16 = **68.75%**（不是两章平均 65%） |

## 四、和组员方案的差别

| 组员方案 | 我们的做法 | 原因 |
|---|---|---|
| 五维（含练习参与率） | 四维 | 参与率学完时基本 100%，没有区分度 |
| 正确率含重做、推荐题 | 只算练习里每道题的第一次作答 | 和“只算第一次”的原则一致；重做和补练另外记 |
| 掌握度：最近 10 次加权、扣蒙对 | 原始掌握度（第一次平均分）+ 补练 → 绿 / 橙 / 红 | 组内已改为简单的第一次作答规则 |
| 掌握度少于 3 次标“证据不足” | 颜色直接显示 | 每个知识点题目按要点出（一般 3 道），第一次作答就有足够证据 |

## 五、还没做的

- 老师看某个学生的四维（现在只有学生自己看）；
- AI 对话的文字反馈（自己讲清 / 提示后讲清）放进每章画像；
- 学完时的画像快照（现在每次打开现算）；
- 单元测试（之后补）。

实测（学生 08，“软件测试”，2026-11-25）：学完 1/2 章，四维未开放；四个数值为持续性 1/7、完成度 6/8、按时完成率暂无数据、正确率 14/20。第 6 章 7 个知识点：4 绿、1 橙、2 红。
