| 07-数据库说明（MySQL） | 7 个存数据的地方（MySQL 主库、H2 文件库、H2 测试库、资料文件、资料处理缓存、浏览器 localStorage、配置文件）逐个说明；表的设计约定；从页面到 SQL 怎么调用；每个 JSON 列的结构；搬数据、备份、恢复；换 MySQL 时修好的问题；33 张表逐张说明（用途、写入时机、关联、索引、谁写谁读、每一列含义、一行真实数据） |
