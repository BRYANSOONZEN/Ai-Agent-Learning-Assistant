## 三、文档怎么保证和代码一致

接口清单、表结构、测试清单、32 张表的说明、42 个功能的 SQL 记录、界面截图都不是手抄的，而是由 `tools/docs/` 下的脚本直接从代码、数据库和运行中的系统生成：

```powershell
python tools/docs/build_docs.py
```

（重新生成接口、表结构、测试、数据库四份文档里的自动部分，并刷新目录；第七节的行数和例子需要本机 MySQL 在运行）

```powershell
node tools/docs/shoot.mjs
```

（重新截图；需要先启动后端 8080 和前端 5173）

```powershell
cd backend
.\mvnw.cmd test -Dtest=SqlTraceIT -Dsurefire.failIfNoSpecifiedTests=false
```

（重新记录 42 个功能执行的 SQL）
