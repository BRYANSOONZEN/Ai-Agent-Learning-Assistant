# 软件工程智能学习平台

Course project: learning → record → diagnose → profile → recommend → intervene (学→记→诊→画→荐→干).

| Folder | Stack | Status |
|---|---|---|
| `frontend/` | Vue 3 + Element Plus + ECharts | Template ready, see [frontend/README.md](frontend/README.md) |
| `backend/` | Spring Boot 3 + MyBatis-Plus + MySQL | Not started |
| `algo/` | Python FastAPI (diagnosis, recommendation, AI features) | Not started |
